1포루틴이란

매일 챙겨야 할 비타민과 영양제를 등록하고, 복용 시간을 알림으로 관리해 주는 앱입니다. 복잡한 가입 없이 Apple·Google 소셜 로그인으로 바로 시작하실 수 있습니다.

  • 복용 알림 · 스케줄 관리
  • 영양제 등록 · 재고 추적
  • 복용 기록 통계
  • 영양소 섭취 분석 (KDRIs 2025 기준)
  • AI 맞춤 루틴 분석 (Plus)

3자주 묻는 질문

로그인이 안 돼요.

포루틴은 Apple 및 Google 소셜 로그인만 지원합니다. 애플 계정·구글 계정에 문제가 있는지 먼저 확인해 주세요. 계속해서 로그인이 되지 않으면 이메일로 알려 주시면 도와드리겠습니다.

비타민이 검색되지 않아요.

식약처 등록 제품을 기준으로 검색됩니다. 검색 결과가 없거나 원하시는 제품이 없을 경우, 직접 입력 기능으로 등록하실 수 있습니다. 정확한 성분·용량 정보를 입력하시면 통계·분석 기능에서 활용됩니다.

알림이 오지 않아요.

iOS 설정 → 알림 → 포루틴 에서 알림이 허용되어 있는지, 앱 안에서 알림 설정이 켜져 있는지 확인해 주세요. 방해 금지 시간 설정이 되어 있으면 그 시간에는 알림이 오지 않습니다.

Plus 구독을 해지하고 싶어요.

iOS 의 경우 설정 → Apple ID → 구독 에서 포루틴 Plus 를 선택해 취소하실 수 있습니다. 취소 시 현재 구독 기간이 끝나는 시점까지는 Plus 기능을 계속 이용하실 수 있습니다.

환불이 가능한가요?

인앱 구독의 환불은 Apple App Store 의 환불 정책이 우선 적용됩니다. reportaproblem.apple.com 에서 환불 신청이 가능합니다.

계정을 삭제하고 싶어요.

앱 안 내 정보 → 회원 탈퇴 에서 직접 진행하실 수 있습니다. 탈퇴 시 등록하신 영양제 목록·복용 기록·설정은 모두 즉시 삭제됩니다.

탈퇴하면 Apple/Google 로그인 연동은 어떻게 되나요?

탈퇴 시 Apple/Google 로그인 연동 해제(토큰 무효화)를 자동으로 요청합니다. 외부 서비스 장애 등으로 요청이 실패할 경우에도 회원 데이터 삭제는 그대로 진행됩니다. 연동 상태를 직접 확인하시려면 기기의 설정에서 확인하실 수 있습니다 (iOS: 설정 → Apple ID → 로그인 방식).

AI 분석 결과를 어디까지 신뢰해야 하나요?

AI 분석은 참고 정보이며, 의료행위·진단·처방을 대체하지 않습니다. 건강 상태·약물 상호작용·부작용 등에 대한 판단은 반드시 의사 또는 약사와 상담하시기 바랍니다.
